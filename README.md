# 🌐 Personal Portfolio Website

Welcome to my personal portfolio! This project showcases my skills, projects, internships, and tools in a visually appealing and responsive format using modern web technologies.

🚀 **Live Preview**: [https://portfolio-plum-ten-17.vercel.app/](https://portfolio-plum-ten-17.vercel.app/)

## ✨ Features

- 🎨 **Modern Design**: Sleek dark gradient background with vibrant orange highlights.
- 🧑‍💻 **About Me**: Learn who I am and what I do.
- 💼 **Internships**: Timeline of internship experiences with descriptions.
- 📁 **Projects**: Grid layout with project images, tech stacks, and GitHub links.
- 💡 **Skills & Tools**: Icons and cards displaying technical proficiencies.
- 📱 **Responsive**: Optimized for desktops, tablets, and smartphones.
- 📄 **Resume Download**: Option to download my resume directly.
- 📬 **Contact Section**: Easy links to GitHub, LinkedIn, and email.

## 🛠️ Technologies Used

- **Frontend**: React.js, HTML5, CSS3
- **Styling**: Custom CSS with media queries for responsiveness
- **Animations**: Simple hover and typewriter animations
- **Deployment**: [Vercel](https://vercel.com/)
